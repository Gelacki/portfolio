Landing Page Barbearia Premium - Agendamento Inteligente

Desenvolvimento de uma interface web moderna e responsiva para uma barbearia, focada na conversão de clientes e facilidade de uso. O projeto substitui agendamentos manuais por um fluxo digital intuitivo. Destaques do Projeto: Design Responsivo: Layout adaptável para mobile e desktop, garantindo acessibilidade em qualquer dispositivo. Sistema de Agendamento: Interface interativa desenvolvida em JavaScript que permite ao usuário selecionar serviço, barbeiro e horário. Integração WhatsApp: Botão flutuante e CTA (Call to Action) que redirecionam os dados do agendamento pré-formatados diretamente para o WhatsApp do estabelecimento. Estilização Avançada: Uso de SASS (SCSS) para arquitetura de CSS modular, utilizando variáveis e mixins para fácil manutenção e consistência visual.
