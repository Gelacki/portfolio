Meus Projetos

Placar Digital Kumite e Gestão de Lutas

Uma aplicação web interativa desenvolvida para auxiliar árbitros e instrutores de Karatê. O projeto combina um scoreboard funcional (seguindo as regras de pontuação de Kumite).

Principais Funcionalidades:
  • Placar em Tempo Real: Controle total de pontos, penalidades e cronômetro via JavaScript.
  • Edição Integrada: Gerenciamento de nomes de atletas e categorias.
  • Interface Intuitiva: Design limpo em CSS puro para leitura rápida.

BookFinder

Desenvolvimento de uma interface web intuitiva dedicada à consulta de acervo bibliográfico. O projeto conecta leitores aos seus livros favoritos através de uma experiência de busca simplificada e um sistema de agendamento direto.

Principais Recursos:
  • Busca Dinâmica: Filtragem em tempo real por título, autor ou gênero via JavaScript.
  • Agendamento: Seleção de data e hora para retirada.
  • Integração Mobile: Envio automático de dados do agendamento via WhatsApp.
  • Design Responsivo: Layout fluido para mobile e desktop com CSS3 (Flexbox/Grid).

Landing Page Barbearia Premium - Agendamento Inteligente

Desenvolvimento de uma interface web moderna e responsiva para uma barbearia, focada na conversão de clientes e facilidade de uso. O projeto substitui agendamentos manuais por um fluxo digital intuitivo.

Destaques do Projeto:
  • Design Responsivo: Layout adaptável para qualquer dispositivo.
  • Agendamento Inteligente: Seleção interativa de serviço, barbeiro e horário via JavaScript.
  • Integração WhatsApp: Redirecionamento automático de dados de agendamento.
