Meus Projetos

Placar Digital Kumite e Gestão de Lutas

Uma aplicação web interativa desenvolvida para auxiliar árbitros e instrutores de Karatê. O projeto combina um scoreboard funcional (seguindo as regras de pontuação de Kumite).

Principais Funcionalidades:
  • Placar em Tempo Real: Controle total de pontos (Yuko, Waza-ari, Ippon), penalidades (C1, C2, C3, Hansoku Chui e Hansoku) e cronômetro de luta manipulados via JavaScript.
  • Edição Integrado: Nome de Atleta, Categoria.
  • Interface Intuitiva: Design limpo feito com CSS puro, garantindo leitura rápida durante a dinâmica ágil de uma luta.

BookFinder

Desenvolvimento de uma interface web intuitiva dedicada à consulta de acervo bibliográfico. O projeto conecta leitores aos seus livros favoritos através de uma experiência de busca simplificada e um sistema de agendamento direto.

Principais Recursos:
  • Busca Dinâmica: Campo de pesquisa interativo que filtra livros por título, autor ou gênero em tempo real utilizando JavaScript.
  • Agendamento de Retirada: Formulário integrado para selecionar data e hora para visita ou retirada do exemplar.
  • Integração Mobile: O sistema gera automaticamente uma mensagem personalizada com o livro escolhido e o horário agendado, enviando os dados via API do WhatsApp.
  • Design Responsivo: Estilização com CSS3 moderno (Flexbox e Grid), garantindo legibilidade e navegação fluida em smartphones e desktops.

Landing Page Barbearia Premium - Agendamento Inteligente

Desenvolvimento de uma interface web moderna e responsiva para uma barbearia, focada na conversão de clientes e facilidade de uso. O projeto substitui agendamentos manuais por um fluxo digital intuitivo.

Destaques do Projeto:
  • Design Responsivo: Layout adaptável para mobile e desktop, garantindo acessibilidade em qualquer dispositivo.
  • Sistema de Agendamento: Interface interativa desenvolvida em JavaScript que permite ao usuário selecionar serviço, barbeiro e horário.
  • Integração WhatsApp: Botão flutuante e CTA (Call to Action) que redirecionam os dados do agendamento pré-formatados diretamente para o WhatsApp do estabelecimento.
  • Estilização Avançada: Uso de SASS (SCSS) para arquitetura de CSS modular, utilizando variáveis e mixins para fácil manutenção e consistência visual.
